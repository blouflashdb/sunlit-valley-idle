# Sunlit Valley Idle

A custom version of the [Society: Sunlit Valley](https://modrinth.com/modpack/society-sunlit-valley) modpack with many more idle and autobattler mechanics.

## Goal

All progression should be possible while AFK. Farming, animal husbandry, processing, trading and combat should become automatable step by step, so the game keeps moving forward without constant input.

## Focus

- **Idle mechanics:** Automated production that keeps running without the player.
- **Autobattler:** Fights and dungeons handled on their own by companions or machines.
- **AFK progression:** Every progression step should be reachable without constant clicking.
